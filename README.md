##What knowledge on Git I consider important:

###_Branching, forking and committing_

```
   git branch new_branch
   git fork new_fork
   git commit -m "Changes X Y Z"
``` 

it fosters cooperation and the social side of programming. Forking takes it even further, by creating a brand new repository for each person. Suited for open-source work. Commits systemise all changes. There are also other commands, and they are secondary (adding, as in staging changes before pushing), or amending in order to modify a commit

There are other features that might be very useful, but those are the bare minimum that makes Git Git.
