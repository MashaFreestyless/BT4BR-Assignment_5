## What knowledge on Git I consider important:

### Branching, forking and committing

```
   
   git branch new_branch #creating a new branch

   git checkout new_branch    #switching branches, 
   git switch -c new_branch   #or alternatively

   git add file1.txt file2.txt #staging files before committing 

   git commit -m "Changes X Y Z" #commit and add a message regarding what was changed

   git commit --amend #changing the last commit

   git push #uploads commits so that others can see them

   git pull #fetching changes in the repo


``` 

it fosters cooperation and the social side of programming. Forking takes it even further (done on GitHub), by creating a brand new repository for each person. Suited for open-source work. Commits systemise all changes. There are also other commands, and they are secondary.

There are other features that might be very useful, but those are the bare minimum that makes Git Git.
